# Enterprise Policy Q&A Bot with Local Ollama RAG

A local Retrieval-Augmented Generation (RAG) assistant designed to answer enterprise policy questions securely using Ollama and Python.

## Features
* Local document ingestion from `enterprise_docs/`
* Context-aware Q&A via `bot.py` and `app.py`
* 100% private execution with Ollama

## Prerequisites
* Python 3.10+
* [Ollama](https://ollama.com/) installed and running locally
